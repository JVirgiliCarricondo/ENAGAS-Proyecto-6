# Recursos de formación

Materiales, ejercicios y enlaces de apoyo. Cada recurso se enlaza desde [`../plan_formativo.md`](../plan_formativo.md).

## Cómo organizar

- Un fichero o subcarpeta por tema (p.ej. `rasters/`, `lcp/`, `fuentes/`).
- Enlaces externos en este README o en un `enlaces.md` por tema.
- Los ejercicios resueltos pueden ir como notebooks en `proyecto/notebooks/`.
